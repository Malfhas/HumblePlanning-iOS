# Changelog

All notable changes to Humble Planning for iOS are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.2] - 2026-11-09

First version of the native iOS app of Humble Planning, with the features of the Android app 1.0.2. It needs a Humble Planning server that includes the mobile API (`/api/mobile`) and accepts iOS devices.
